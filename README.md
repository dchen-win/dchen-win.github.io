## How the site is built

A single static page: `index.html` contains the HTML, CSS, and a small amount of JavaScript. There is no build step.

```
index.html              the whole site
images/                 photos, logos, and project icons
Resume Cindy Chen.pdf   downloadable resume
```

To preview locally, open `index.html` in a browser. Pushing to `main` publishes it through GitHub Pages.
